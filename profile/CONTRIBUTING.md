# Contributing to izon446-lab

1. Pick an issue labeled `good first issue` or `help wanted`.
2. Keep PRs small: one concern, reviewable in minutes.
3. Attach Proof: evidence (commands + output) that matches your head SHA.
4. Tests are welcome, but Proof ≠ tests — show it actually works.
5. Work L0 by default: no broad refactors, no surprise dependencies.
6. Be kind in reviews. Questions → open a Discussion or ping @izon446.
